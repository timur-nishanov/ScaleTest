# Yandex Cloud — «Собери свой идеальный бандл»

Интерактив для конференции Yandex Scale 2026: тач-экран 4K (55″, 3840×2160) + веб-версия для рассылки пользователям.

Гость выбирает бизнес-задачу и собирает под неё связку сервисов платформы данных — сам (drag-and-drop) или выбором из готовых бандлов (режим с монетой за конкурс).

## Запуск

```bash
npm install
npm run dev        # дев-сервер
npm run build      # прод-сборка в dist/
npm run preview    # предпросмотр прод-сборки
```

Параметры URL:

- `?mode=web` — веб-режим (по умолчанию `kiosk`).

## Как устроено

- Вся вёрстка ведётся в **дизайн-координатах 3840×2160** (1:1 с макетами Figma). Компонент `Stage` масштабирует сцену под фактический вьюпорт (letterbox) — поэтому интерактив можно смотреть на любом экране без переписывания вёрстки.
- Экраны — конечный автомат (`src/app/flow.ts`, zustand), без роутера.
- Контент (задачи, бандлы, сервисы, тексты) отделён от компонентов: `src/data/*`. Правки текстов не трогают код.
- Аналитика — контракт событий по ТЗ (`src/analytics/`), транспорт подключаемый (пока локальная очередь; бэкенд — отдельный этап).

## Структура

```
src/
  app/        Stage, конечный автомат экранов, конфиг (таймер, idle, флаги)
  screens/    Attract / Mode / TaskSelect (колесо карточек) / Build / Ready + Result-оверлей
  components/ ui-кит (кнопки, теги, плитки сервисов, слоты), колесо-карусель, drag-слой
  data/       сервисы, задачи «собери сам», задачи и бандлы «выбери готовое», факты
  analytics/  контракт событий + очередь/отправка
  lib/        хуки: таймер, idle-сброс, масштабирование, нажатия (scale 0.94)
  styles/     токены (палитра/типографика — заполняются из брендбука) + база
public/assets/ шрифты, логотип, иконки сервисов, иллюстрации  ← сюда заливать ассеты
docs/          план работ, разбор макетов, рефы взаимодействий, схема аналитики
prototype/     согласованный кликабельный прототип (референс логики)
```

## Куда класть ассеты

См. `public/assets/README.md`. Кратко: шрифты → `assets/fonts`, логотип → `assets/logo`, иконки сервисов → `assets/icons`, иллюстрации карточек/попапов → `assets/illustrations`. Имена файлов — ключи сервисов из `src/data/services.ts`.

## Документация

- `docs/PLAN.md` — план внедрения по этапам, ограничения, открытые вопросы.
- `docs/DESIGN-NOTES.md` — инвентаризация Figma (node id всех экранов/стейтов), расхождения ТЗ ↔ макетов.
- `docs/REFS.md` — декомпозиция референсов взаимодействия (интро-прокрутка, колесо карточек).
- `docs/ANALYTICS.md` — схема логирования для пост-анализа.
